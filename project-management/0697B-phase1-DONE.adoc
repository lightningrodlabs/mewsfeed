=== Key Design Decisions

JSON-LD field mapping::
  `@context` -> `#[serde(rename = "@context")] pub context: serde_json::Value` +
  `type` -> `#[serde(rename = "type")] pub actor_type: String` (or `note_type`, etc.)

`serde_json::Value` for `@context`::
  Mastodon emits `@context` as either a plain string or an array with inline
  extension objects. Using `Value` handles both without custom deserializers.

Flat `APActivity` struct (not a Rust enum)::
  Real AP JSON uses a `"type"` discriminant with a polymorphic `"object"` field
  (sometimes a string URI, sometimes a nested object, sometimes an array).
  A flat struct with `object: serde_json::Value` avoids fragile
  `#[serde(untagged)]` enum issues. Type-safe constructors/accessors come in Phase 3.

All structs use `#[serde(rename_all = "camelCase")]`::
  ActivityPub JSON uses camelCase field names.

Optional fields use `#[serde(skip_serializing_if = "...")]`::
  Omits `null` fields from serialized output, matching Mastodon's behavior.
